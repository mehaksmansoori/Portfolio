# Mehak Shaikh Mansoori — Portfolio

A responsive portfolio for an ECE and AI student at IGDTUW, featuring research at IIT Kharagpur and DRDO, AI and software projects, technical skills, and achievements.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Files

- `index.html`: portfolio content
- `styles.css`: styling and responsive layouts
- `script.js`: navigation, reveal animations, and email draft handling
- `images/`: profile photos
- `Resume_MehakShaikh.pdf`: downloadable resume

## Contact

The contact form opens a draft in the visitor's email app. Visitors must send the email themselves.

## Hosting

The existing site uses GitHub Pages at https://mehaksmansoori.github.io/Portfolio/.
